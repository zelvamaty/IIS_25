# Backend tests

## Requirements
    * Python 3.12 or later

## Configure environment

Linux:
```
python3 -m venv .venv
source .venv/bin/activate
pip install -U -r requirements.txt
```

Windows (PowerShell):
```
python3 -m venv .venv
. .\.venv\Scripts\Activate.ps1
pip install -U -r requirements.txt
```

macOS: TBD

## Run tests:
```
pytest
```
